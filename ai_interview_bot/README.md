# AI Interview Preparation Bot (Python / Flask Package)

Portable Python + Flask + SQLite + Gemini AI reference implementation.

## Quick Start

```bash
cd ai_interview_bot
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Add your GEMINI_API_KEY and FLASK_SECRET_KEY in .env
python app.py
```

Open `http://localhost:5000` in your browser.
